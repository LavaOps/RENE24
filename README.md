# MORPHQ++ Artifacts

Artifacts for RENE 2024 Workshop paper

Linsey Kitt, Myra B. Cohen,MorphQ++: A Reproducibility Study of Metamorphic Testing on Quantum Compilers, Replications and Negative Results (RENE), an @ASE workshop, October 2024. Link to paper: https://dl.acm.org/doi/10.1145/3695750.3695823


This repository contains:

1. The seven new transformations (.py programs)
2. A full (text) log of one of the three 48 hour runs
   (log_one_run.tar.gz).  Use gzip and tar to extract this file. 
3. The data base (qfl.db.gz) for the same run. This can be used to
   recreate the graphs using the MorphQ notebooks. Use gzip and tar to extract the database.
